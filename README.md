# DSList

REST API for managing and organizing games, developed with Java and Spring Boot.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL

## Features

- List games
- View game details
- Organize games into lists
- Reorder games within a list

## Getting Started

### Requirements

- Java
- PostgreSQL
- Maven
